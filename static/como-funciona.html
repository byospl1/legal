Cómo funciona el sistema

Guía rápida para llenar la portada de exhibits (Tab cover) de un I-589, subir la evidencia y obtener el PDF final listo para imprimir o archivar.

1

Captura o selecciona el caso

En Inicio, si el caso ya existe elígelo en "Caso existente" — se rellenan solos el nombre, A#, corte, juez, etc. Si es nuevo, captura los datos y da clic en Guardar caso.

  • Si el expediente tiene más de un A# (cónyuge, hijos), agrégalos como riders. El sistema arma solo el "{nombre} et al" y el "A# líder/últimos 3 dígitos de cada rider" donde corresponda.
  • Guardar el caso también recuerda en qué página se quedó el expediente la última vez, para sugerir automáticamente la siguiente página al generar un nuevo Tab.
2

Elige la plantilla y agrega los Tabs

Selecciona la plantilla y el título del documento. Si la plantilla lleva tabla de exhibits, aparece la sección de Tabs — agrega uno por cada letra (A, B, C…) y marca las categorías de contenido que lleva.

  • La letra del siguiente Tab y la página inicial se sugieren solas según el último Tab guardado del caso — puedes corregirlas si hace falta.
  • Cada categoría puede llevar uno o varios documentos, según el tipo de Tab (ver la sección de categorías más abajo).
3

Sube la evidencia en PDF

Por cada documento del Tab (I-589, Country Report, pasaporte, noticia, recibo de Fee, etc.) sube su PDF. El sistema cuenta las páginas y calcula solo el rango donde queda cada uno, encadenado desde la página inicial del lote.

  • Para Country Conditions / OSAC, el sistema intenta detectar el país y el año leyendo el PDF — siempre puedes corregir la sugerencia.
  • Para el recibo de Fee, detecta si es "Initial" o "Annual" buscando la frase exacta "Initial Application Fee" en el documento.
  • Para una noticia (News), sugiere el título leyendo la primera línea del PDF — revísalo, porque no siempre acierta el titular exacto.
4

Genera el documento

Da clic en Generar documento. El sistema llena la plantilla, arma la tabla de exhibits y las páginas divisorias "EXHIBIT {letra}", y — si hay evidencia adjunta — convierte todo a PDF y la inserta automáticamente justo después de cada divisoria (antes de "Proof of Service"), con número de página al pie de cada hoja.

  • Si algún Tab tiene evidencia, el sistema genera un PDF por Tab de forma automática (no se pueden combinar varios Tabs con evidencia en un solo archivo).
  • La conversión a PDF usa Word en segundo plano, así el formato y las fuentes quedan idénticos al documento original.
5

Descarga y revisa

Los enlaces de descarga (.docx y .pdf) aparecen debajo del botón, y también quedan listados en Documentos generados con miniaturas de verificación visual. Cada archivo se guarda con un nombre único (cliente, A# y tipo de Tab) para que nunca se sobreescriba uno anterior.

Categorías de contenido por Tab

I-589

I-589 Application

La aplicación de asilo en sí. Un solo documento.

CC

Country Conditions

Country Report + OSAC Report del país de origen. País y años se detectan del PDF, editable.

ID

Form of Identity

Un documento de identidad (pasaporte, acta de nacimiento o ID) por cada persona del caso — el aplicante líder y cada rider, cada quien con su propio archivo y rango de páginas.

SE

Supplemental Evidence

Varios documentos de apoyo (Declaration, Psychological Report, noticias). En noticias, el título del artículo se inserta en el subtítulo de esa línea.

FEE

Fee

Recibo de pago (Initial o Annual, detectado automáticamente) y/o huellas del FBI — cada uno se muestra solo si se sube su archivo.

Preguntas frecuentes

¿Por qué no me deja combinar varios Tabs con evidencia en un solo archivo?

Porque cada Tab con evidencia necesita insertar sus propias páginas justo después de su propia divisoria "EXHIBIT {letra}" — si se combinan, no habría forma de saber dónde termina un Tab y empieza el siguiente dentro del mismo PDF. Por eso, en cuanto un Tab lleva un archivo adjunto, el sistema genera automáticamente un PDF separado por Tab.

¿Qué pasa si me equivoco en la página inicial del lote?

Puedes corregirla a mano antes de generar — el sistema solo la sugiere con base en la última página guardada del caso, nunca la impone.

¿Dónde se guardan los documentos generados?

En la carpeta output/ del programa, con un nombre único por corrida (cliente, A# y tipo de Tab) para que nunca se sobreescriba un archivo anterior. También aparecen listados en la sección "Documentos generados" de la pantalla de Inicio.

El PDF generado no tiene las mismas fuentes que el Word original, ¿qué hago?

Asegúrate de tener Microsoft Word instalado y cerrado (sin otro documento abierto) cuando generes el PDF — el sistema lo usa en segundo plano para convertir con fidelidad exacta. Si Word no está disponible, usa LibreOffice como respaldo, aunque puede variar ligeramente el formato de algunas fuentes.

¿Puedo tener más de un A# en el mismo caso?

Sí — agrega cada co-aplicante (cónyuge, hijos) como "rider" en el paso 1. El documento mostrará "{nombre del cliente} et al" y el A# como "{A# líder}/{últimos 3 dígitos de cada rider}" automáticamente, incluyendo los ajustes de "Respondent" → "Respondents" donde corresponde.

¿Algo no se ve bien o falta un caso que no está contemplado aquí? Avísale a Hugo con una captura de pantalla — este sistema se ajusta seguido según los expedientes reales del despacho.
